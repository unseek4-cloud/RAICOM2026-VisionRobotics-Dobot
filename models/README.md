# YOLO 模型目录

- `task2.pt`：任务二 OBB 权重，至少能区分立方体/圆柱体；颜色可由模型类别或 HSV 兜底。
- `task3.pt`：任务三 OBB 权重，识别顶部不干胶图案；现场任务书发布后重新采集、四点标注、训练。

模型文件体积较大且必须按现场道具训练，所以本项目不放置虚假的权重。缺少权重时
模拟模式仍可完整运行，真机模式会在启动前拒绝执行并明确提示。

正式权重必须是 Ultralytics `task=obb`。仓库旧的 `task=detect` 水平框权重不含
工件角度，不能用于 RZ 抓取；请使用 `yolo11n-obb.pt` 等本地 OBB 基础权重重训。
